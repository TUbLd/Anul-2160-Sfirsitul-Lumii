# Anul-2160-Sfirsitul-Lumii
Această carte mică prezintă un studiu cronologic și simbolic bazat pe numere și perioade descrise in texte vechi. Analizează relațiile dintre zile, luni, ani, generații și jubilee, care arată anul 2160 ca moment al sfârșitului lumii actuale. Invită la reflecție asupra înțelepciunii, responsabilității umane, păcii și unității.
